One quiet place for every book you own.

eParna is a fast, lightweight, cross-platform ebook reader. The name comes from Sanskrit पर्ण (parṇa) — leaf. A page is a leaf, so eParna is an “e-leaf”: a light, quiet place to read. Built on ebook-rs for multi-format parsing and gpui-kit for a GPU-accelerated, native-feeling UI. 

$ curl -fsSL https://github.com/SV-stark/eParna/releases/latest/download/eparna-installer.sh | sh

Windows (.msi) macOS (.pkg) Linux (AppImage) All releases & checksums →

Prebuilt installers are attached to every GitHub Release: a Windows MSI (with Start Menu shortcut, embedded icon, and Open with registration for supported formats) plus portable ZIP, macOS PKG installers (Apple Silicon & Intel), a single-file Linux AppImage, and a .tar.xz for minimal systems. Every artifact ships with a .sha256 sidecar.

Requires Rust 1.90+ to build from source (edition 2024). The release binary at target/release/eparna uses LTO and opt-level 3 for a fast start.

Everything you need to actually read

A focused reader that stays out of the way — with the details that make long sessions comfortable.

Library view

A cover-forward grid (up to 3 MiB covers + SVG) with “Continue reading”, filtering, sorting, favourites and one-click reopen.

Highlights & notes

Select across blocks, copy and save passages. Click any note to jump back to it, or export everything as Markdown.

Full-text search

Find anything in a book with snippets, jump-to-result, regex mode and a configurable result cap.

TOC & interactive scrubber

Hierarchical table of contents plus a clickable progress scrubber with chapter ticks, hover preview, and live scroll tracking.

Custom GPUI renderer & themes

Native CSS borders, padding, tables and lists, 1-click theme swatches, typeface/alignment controls, and a collapsible sidebar.

OS Text-to-Speech & dictionaries

Read sections or selections aloud with built-in OS TTS (0.5x–2.5x), or look up words in StarDict and Wikipedia.

Every format

EPUB, MOBI, AZW3, KFX, PDF, FB2, CBZ, DOCX and more — detected automatically from file contents.

Private by default

Reading is fully offline. Recent books, notes and settings stay on your device — nothing is uploaded.

OPDS catalogues

Browse and download books from OPDS feeds, then open them straight into the reader.

Footnotes & lightbox

Inline footnote popups, cross-document links and a full-size image lightbox keep the book intact.

Reliable resume

Position is stored as a Readium CFI, returning you to the same passage even after re-conversion.

Export, optimize & citations

Convert any book across 22+ formats (EPUB 3, KEPUB, KFX, MOBI, AZW3, LIT, PDF, DOCX, Markdown & RAG JSON), optimize EPUBs, validate structure, and copy BibTeX/APA/MLA/Chicago citations.

Made for long reading sessions

The little things add up. Everything here is in the default view or one click away.

  • Eight reading themes + custom. Light, Dark, OLED Black, Sepia, Nord, Solarized, Solarized Dark, E-Ink, plus custom background/foreground hex colors.
  • Reading statistics. Section word count, WPM-calibrated time remaining, and session reading time live in the status line.
  • Nested TOC & print pages. Hierarchical chapters and sub-items are indented, with deep search and breadcrumbs.
  • Inlined assets. Images are embedded by ebook-rs, so sections render offline.
  • Deduplication. Opening the same book from another path updates the existing entry via a content hash.
  • Zen mode & fullscreen. Press Z for distraction-free reading or F11 for fullscreen.
  • LCP passphrase & DRM. Protected books can be opened by entering a passphrase.
